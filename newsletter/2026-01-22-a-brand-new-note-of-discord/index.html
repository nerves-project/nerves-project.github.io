A new space

I don't know exactly when it happened. The #nerves channel on the Elixir Slack got pretty quiet over the last few years. It was my preferred zone. The #nerves on the Elixir Discord had been quiet for ages. We started to direct support threads to Elixir Forum for a while which did help get solutions publicly documented and helped make sure threads about Raspberry Pi display troubles could resurface when they needed to.

I got a bit more active in the Discord as I was being more active on other Discords. And Goatmire Elixir feat. NervesConf in 2025 had a Discord which whipped a lot of people into action. And some of that then seemed to spill over into #nerves on the Elixir Discord. Activity begets activity and suddenly that space was fairly active.

We started talking to the mods about more channels and doing some special integrations but we couldn't quite find the path there so now we've done it. We took the Nerves Meetup EU Discord server that was created as part of the meetup and reworked it. It is now the dedicated Nerves Discord server .

Discords are good for chat and has great moderation tools. It offers a lot more for us than a Slack free plan with 90-day amnesia. What Discord sucks at is openness and we are an open project. So we took our cues from the very successful Ash Discord and set up Answer Overflow. A Discord bot integration dealio that makes the #questions channel a public resource as we answer questions. Building that knowledge bank that has been so hard for Nerves to maintain.

We of the Nerves team aren't leaving the existing channels. We'll encourage moving over to gather the community but we want to capture people's excitement where they are.

Big thanks to Gus Workman, Ellyse Cedeno, Frank Hunleth and the rest of the people consulted for pulling together rules, updating CoC, and generally just leveling up our foundational community bits for this next step.

Now you can finally share stuff that won't be completely lost after 90 days. Hope you'll join us: https://discord.gg/7TqSpepHw7

Software updates

nerves, v1.13.0

This release adds the nerves.discover mix task to make it easier to find Nerves devices. It discovers devices using mDNS and reports existing devices that have hostnames starting with “nerves-“. See nerves_discovery for updating your projects to return much more information.

  • Changes
    • Documentation updates including more information for beginners. (@mlainez)
    • Return error exit status when mix burn fails

nerves_motd, v0.1.17

  • Improvements

    • Add firmware nickname to top line describing the firmware version. This makes it easier to check when the firmware UUID changes. Support is ongoing other places in Nerves to make the nickname more visible.

    • Use Nerves.firmware_slots/0 to determine the active firmware slot to support firmware slot changes that aren’t represented in the KV. This is for Raspberry Pi tryboot support.

  • Bug fixes

    • Fix cases where nils returned when porting Nerves could crash the MOTD print out.

    Got questions?

    Trouble-shooting is best done on the Nerves Forum over at Elixir's Forum. But if you have big-picture questions you would like to ask around Nerves, feel free to send them in and we might just have ourselves a column here.

    Participating in the community

    The Nerves community is found wherever Elixirists gather. But our primary focus is the Nerves Discord . You are very welcome to join us there.

    Also fine to throw questions into the Elixir Forum's Nerves section .

    How you can help Nerves

    Contribute in the way that works for you:

    • Send corrections or improvements for documentation wherever it fails to help you.
    • Write about Nerves, give talks about Nerves. Make videos about Nerves. It is all good.
    • Write or port a new hardware library and include it in the Elixir Circuits collection .
    • Get in touch about taking over maintenance duties for some libraries, we might be able to provide you hardware.
    • Apply for an EEF stipend on something Nerves-related and build it. We can help if you have questions about this.

    Finally, if you have questions about the newsletter or want to suggest something you can simply respond to this email.
